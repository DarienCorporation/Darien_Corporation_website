# Darien Corporation — Website

The official website for Darien Corporation. Built with Next.js 16 (App Router), React 19, TypeScript, and CSS Modules. No animation or UI libraries: motion uses CSS, IntersectionObserver, and scroll-driven animations.

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run typecheck
```

> **iCloud Desktop note:** this project lives in an iCloud-synced folder. iCloud can evict files inside `node_modules` and `.next`, which breaks builds with odd errors. Exclude them from sync after installing:
>
> ```bash
> xattr -w 'com.apple.fileprovider.ignore#P' 1 node_modules .next
> ```
>
> Moving the project outside `~/Desktop` / `~/Documents` avoids the issue entirely.

## Configuration

Copy `.env.example` to `.env.local` and fill in what applies. Anything left empty is simply not shown on the site.

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Production URL. Used for canonical URLs, sitemap, robots, Open Graph. **Required in production.** |
| `NEXT_PUBLIC_CONTACT_EMAIL` | Overrides the public contact email (default: `dariencorporation@gmail.com`, set in `lib/site.ts`). |
| `NEXT_PUBLIC_SOCIAL_LINKEDIN` / `_X` / `_GITHUB` | Real social profiles only. |
| `RESEND_API_KEY`, `CONTACT_FORM_TO`, `CONTACT_FORM_FROM` | Server-only. Replaces the "Write to us" email composer with a server-delivered contact form (via [Resend](https://resend.com)) when all three are set. |

## Routes

| Route | Content |
| --- | --- |
| `/` | Hero and previews of every section |
| `/about` | Company, principles, leadership |
| `/technology` | Interactive technology explorer (tabs, keyboard arrows) |
| `/projects`, `/projects/[slug]` | Project list and detail pages (artwork morphs between them) |
| `/vision` | Draggable Now → Horizon scrubber and research directions |
| `/contact` | Email, copy button, and a composer that opens the visitor's mail app |
| `/privacy`, `/terms` | Legal pages with a switch and "On this page" contents |

Navigation uses React `<ViewTransition>`. Pages slide forward or back based on their order in `lib/navigation.ts`, the header stays anchored, and project artwork morphs between list and detail. Press ⌘K / Ctrl+K (or `/`) anywhere for quick navigation. Browsers without View Transitions support simply navigate instantly.

## Structure

```
app/                 routes, metadata, robots/sitemap/manifest, OG image, /api/contact
components/
  layout/            Header, Footer, LegalPage (+ legal switch and contents)
  navigation/        NavLink (directional transitions), PageTransition, CommandMenu (⌘K)
  sections/          Hero, About, Technology, Projects, Vision, Company, Contact (+ artwork)
  ui/                Button, Container, Logo, SectionHeading, SplitText, Icons
  effects/           RevealObserver, PointerEffects (small client runtimes)
lib/
  site.ts            site config (name, URL, contact, social, navigation)
  navigation.ts      page order used for transition direction
  content.ts         capabilities, projects, vision areas, principles, leadership
  contact.ts         shared form validation; contact-server.ts is server-only
assets/brand/        original logo artwork (source of truth)
public/brand/        web logo generated by `npm run brand`
```

### Editing content

- **Add a project:** append to `projects` in `lib/content.ts`. Optional `href` links to its site, and optional `image` (a file in `/public`) replaces the generated artwork.
- **Add a leader:** append to `leadership` in `lib/content.ts`.
- **Logo:** replace `assets/brand/darien-corporation-logo-source.jpg` and run `npm run brand`. The script only trims whitespace and makes the white background transparent; it never alters the artwork. A vector (SVG) master would render sharper at large sizes.

## Content rules

The site describes only what is true today. Aerospace, mobility, spacetime, and bionics appear only in the Vision section and are clearly labelled as long-term research directions. Don't add metrics, customers, partners, or testimonials unless they are real.

## Security

- Security headers (CSP, HSTS, frame, referrer, and permissions policies) are set in `next.config.ts`.
- `/api/contact` checks same-origin, content type, body size, a honeypot, a per-instance rate limit, and validates on the server. Messages are sent as plain text. The rate limit is in-memory; use a shared store if you run multiple instances.
